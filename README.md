# GridFormula 类电子表格公式编辑器

技术栈：Vue 3、TypeScript、Vite、Vuetify、Pinia、Vue Router。

## 功能

- 1000 行、26 列虚拟滚动表格，支持编辑、区域选择、复制粘贴与键盘导航。
- 支持冻结首行、首列。
- 公式支持四则运算、括号、单元格引用、区域引用、SUM、AVERAGE、MIN、MAX、COUNT、IF、ROUND、ABS。
- 基于依赖图检测循环引用，并返回 `#CYCLE!` 等错误。
- 编辑后只重算直接和间接受影响的公式单元格。
- 支持撤销重做和 CSV 导出。

## 修订合并（多标签页同时编辑）

把工作簿和每次编辑接成只增的修订记录，解决「后保存覆盖先保存」与「公式链旧结果盖回新值」。

- **会话号 / 基线版本 / 操作号**：每个标签页有独立会话号；每次编辑生成一条操作（`会话号:操作号`），并携带创建时的版本向量作为基线。
- **不同单元格直接合并**：基于版本向量做因果合并，不同单元格的操作交换律成立，结果与到达顺序无关。
- **同格两版待选**：同格两边并发修改（互不相见）时判为冲突，保留两版供选择，不自动覆盖；采用某版即追加一条背书操作。
- **只让受影响公式失效**：编辑后按依赖图标记受影响单元格为重算脏集，无关公式保留原值。
- **在算旧批次作废**：重算按批次代数围栏，新编辑一旦产生，旧批次结果一律丢弃，绝不盖回新值。
- **失败重试 + 保留上次有效值**：重算失败自动重试，仍失败则保留该单元格上次成功计算的值。
- **恢复与幂等回放**：刷新后从最后完整操作继续；按 `opId` 去重，重复回放不追加。
- **导出合并当前版本**：CSV 导出来自合并后的当前工作簿。

跨标签页通过 `BroadcastChannel` 实时同步，`storage` 事件兜底；操作按会话分键持久化到 localStorage。
