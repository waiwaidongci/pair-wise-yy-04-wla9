# GridFormula 类电子表格公式编辑器

技术栈：Vue 3、TypeScript、Vite、Vuetify、Pinia、Vue Router。

## 功能

- 1000 行、26 列虚拟滚动表格，支持编辑、区域选择、复制粘贴与键盘导航。
- 支持冻结首行、首列。
- 公式支持四则运算、括号、单元格引用、区域引用、SUM、AVERAGE、MIN、MAX、COUNT、IF、ROUND、ABS。
- 基于依赖图检测循环引用，并返回 `#CYCLE!` 等错误。
- 支持撤销重做和 CSV 导出。

## 协作与修订记录

工作簿与编辑操作接成了修订记录，多标签页同时编辑不会互相覆盖：

- **修订记录**：每次编辑产生一条操作（op），携带会话号（每标签页一个）、基线版本（编辑时所见的日志版本）和会话内递增的操作号；共享操作日志持久化在 `localStorage`，跨标签页通过 `BroadcastChannel` + `storage` 事件同步。
- **并发合并**：不同单元格的修改直接合并；同一单元格两边都改过（对方基线之后本地也改过）则保留两版，在「协作」面板中二选一，任一方解决后双方收敛。
- **增量失效**：任一格改动只让依赖图中受影响的公式失效；重算分批异步执行，期间有新改动则旧批次整批作废（旧结果不会盖回新值）；批次失败自动重试，仍失败则保留上次有效值并标记错误。
- **崩溃恢复**：本地快照记录最后完整操作的版本，刷新/重开后从该版本继续回放日志；回放按 op id 幂等去重，重复回放不追加；CSV 导出的是合并后的当前版本。
- 撤销/重做以格子级逆操作接入同一条修订记录，不会冲掉远程合并进来的内容。

点工具栏「新标签页」再开一个页面即可体验协作；「协作」面板可查看修订记录、处理同格冲突。

## 运行

```bash
corepack pnpm install
corepack pnpm dev
corepack pnpm build
corepack pnpm test:integration   # 模拟两个标签页的合并/冲突/恢复行为测试
```
